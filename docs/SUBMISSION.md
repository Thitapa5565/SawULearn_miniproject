# ขอบเขตชุดส่งงาน

จัดจากโปรเจกต์ SawUAI วันที่ 11 ตุลาคม 2026 เพื่อส่งอาจารย์ โดยคงรุ่นโมเดล `combined_experts_20261007_211339_512861`

## ส่วนที่คงเดิม

- ไฟล์โมเดล final ทั้ง 4 ตัวและไฟล์สำหรับเปรียบเทียบ Validation เป็นไฟล์ต้นฉบับ
- Feature CSV, audit CSV และ manifest ของ Train/Validation/Test คง bytes และ SHA256 เดิม
- สูตร posture geometry / torso-hand geometry, guard ของการจับเริ่มต้น และคำทำนายจากโมเดลเหมือนรุ่นที่เปิดใช้
- หน้าฝึก React และขั้นตอน 10 วินาที / ยกนิ้วโป้ง / เทียบเสียง ±5 Hz ใช้โค้ดรุ่นปัจจุบัน
- Notebook ล่าสุดทั้ง 3 เล่มยังมีผลรัน กราฟ ตาราง และคำอธิบายเดิม
- ผลคะแนนและข้อมูล provenance ของรอบฝึกเดิมคงไว้เป็นหลักฐาน ห้ามอ่าน `deployed=False` ใน training record ว่าเว็บไม่ได้ใช้โมเดล เพราะเป็นสถานะขณะฝึก ส่วน deployment ปัจจุบันอยู่ใน `web_app/backend/combined_model.json`

## ปรับเพื่อให้เป็นชุด standalone

- Backend โหลดโมเดล final ล่าสุดโดยตรง ไม่ต้องโหลดแพ็กเกจโมเดลเก่าก่อน ไม่พึ่ง raw clip หรือ frame index เก่าเมื่อเริ่มเซิร์ฟเวอร์
- เก็บเฉพาะ API และส่วน UI ที่ใช้ใน flow ปัจจุบัน ตัด API ของการมาร์ก/ติดตาม A–E และหน้าตรวจ Label เดิมออก
- เปลี่ยนภาพสาธิตเป็นภาพนิ่งที่แนบใน `web_app/public/examples/`
- เปลี่ยน Notebook kernelspec เป็น Python 3 ทั่วไป เลือก environment `.venv` ของโฟลเดอร์ที่โคลน และตรวจ deployment ที่มีในชุดส่งแทน pointer ของโมเดลเก่า
- Run All ของเล่ม 01 เมื่อ `TRAIN_NEW=False` ไม่เขียนทับ training record ต้นฉบับ
- แนบเว็บที่ build แล้ว และ requirements ที่ระบุรุ่นสำหรับติดตั้งใหม่

ไม่มีการฝึกโมเดลใหม่หรือเปลี่ยนคำตอบเพื่อให้คะแนนดีขึ้นในการจัดชุดส่งครั้งนี้ การทดสอบคำทำนายใช้ Feature CSV เดิมเทียบกับ prediction CSV เดิม

## สิ่งที่ไม่รวม

คลิปต้นฉบับทั้งหมด, environment `.venv`, `node_modules`, ไฟล์ cache/log ชั่วคราว, API key, ใบรับรอง/private key ของ iPad, เอกสารที่ผู้ใช้ยังแก้ส่วนตัว, โมเดลทดลองก่อนหน้า และ Notebook รุ่นเก่า

ภาพในตัวอย่างและ Notebook เป็นข้อมูลจากการเก็บชุดนี้ ไม่ใช่ข้อมูลประเมินอิสระจากผู้เล่นใหม่ การฝึกซ้ำในชุดส่งเริ่มจาก Feature ที่เตรียมไว้แล้ว หากจะสกัดจากวิดีโอต้นฉบับใหม่ต้องใช้ชุดข้อมูล/เครื่องมือเตรียมข้อมูลในโปรเจกต์ต้นทางเพิ่มเติม
